# NexaOS - Smart Business Management SaaS Platform

NexaOS is a unified, smart business management platform built for freelancers, agencies, startups, and modern businesses. It combines CRM, project management, invoicing, payments, team collaboration, workflow automations, and business analytics into one seamless dashboard interface.

---

## 🚀 Key Features

- **Executive Overview Dashboard**: High-level KPI metrics, revenue charts, upcoming deadlines, pending invoices, recent activity feeds, and quick actions.
- **CRM & Lead Pipeline**: Visual Kanban board with drag-and-drop pipeline stages, lead conversion tracking, estimated values, and contact detail drawer.
- **Client Management**: Complete client directory with revenue tracking, active projects, associated invoices, and history.
- **Project Tracking & Milestones**: Table and card views, priority levels, milestone progress bars, and linked team members.
- **Task Management**: List, Kanban, and Calendar views with priority badges, due dates, and status management.
- **Invoicing & PDF Export**: Professional invoice generator with status tracking (Paid, Pending, Overdue), itemized line items, and print/PDF export.
- **Payments & Transactions**: Financial transaction records, payment methods, and automated receipt creation.
- **Team Collaboration**: Role-based permissions, member profiles, capacity tracking, and direct email contacts.
- **Workflow Automations**: Pre-configured triggers and actions for automated email alerts, invoice reminders, and stage transitions.
- **Business Analytics**: Interactive visual charts powered by Recharts, revenue projections, category breakdowns, and exportable reports.
- **Document Management**: Centralized file manager with categorization, search, and storage usage metrics.
- **Smart Mobile Experience**: Seamless responsive UI with device detection notice and instructions for desktop optimization.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand) (with persistent storage)
- **Date Formatting**: [date-fns](https://date-fns.org/)

## 🏁 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aniket7818/nexaos.git
   cd nexaos
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm start
```
